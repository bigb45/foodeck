# Foodeck - Restaurant Management System

A multi-module Android application for restaurant ordering, built with Jetpack Compose and Clean Architecture.

## Tech Stack
- Kotlin, Jetpack Compose
- MVVM + Clean Architecture
- Multi-module (features: auth, menu, cart, orders)
- Hilt for DI
- Room for local storage
- Retrofit for API calls
- Coroutines + Flow

## Features
- Browse menu with categories
- Add items to cart with offline persistence
- Place and track orders
